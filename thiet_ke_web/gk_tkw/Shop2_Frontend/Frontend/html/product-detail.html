Bảng size chỉ mang tính tham khảo. Nếu thích mặc rộng, bạn có thể chọn lớn hơn 1 size.

Lưu ý khi chọn size

  • Form regular: chọn đúng size thường mặc.
  • Form oversize: có thể chọn đúng size vẫn rộng thoải mái.
  • Nếu ở giữa 2 mức cân nặng, ưu tiên chọn size lớn hơn để dễ mặc hơn.
