Tra cứu nhanh các quy luật logic, quy tắc suy diễn, công thức đếm và đại số Bool chuẩn xác.

⚖ 10 Quy luật Logic cơ bản

Quy luậtBiểu thức tương đương
1. Phủ định của phủ định¬(¬p) ⇔ p
2. De Morgan¬(p ∧ q) ⇔ ¬p ∨ ¬q
¬(p ∨ q) ⇔ ¬p ∧ ¬q
3. Giao hoánp ∨ q ⇔ q ∨ p
p ∧ q ⇔ q ∧ p
4. Kết hợp(p ∨ q) ∨ r ⇔ p ∨ (q ∨ r)
(p ∧ q) ∧ r ⇔ p ∧ (q ∧ r)
5. Phân bốp ∧ (q ∨ r) ⇔ (p ∧ q) ∨ (p ∧ r)
p ∨ (q ∧ r) ⇔ (p ∨ q) ∧ (p ∨ r)
6. Lũy đẳngp ∨ p ⇔ p; p ∧ p ⇔ p
7. Trung hòap ∨ 0 ⇔ p; p ∧ 1 ⇔ p
8. Phần tử bùp ∨ ¬p ⇔ 1; p ∧ ¬p ⇔ 0
9. Thống trịp ∨ 1 ⇔ 1; p ∧ 0 ⇔ 0
10. Hấp thụp ∨ (p ∧ q) ⇔ p
p ∧ (p ∨ q) ⇔ p

🔁 Quy luật Kéo theo & Luật phản đảo

Quy luật / Dạng mệnh đềBiểu thức tương đương
Định nghĩa phép kéo theop → q ⇔ ¬p ∨ q
Phủ định phép kéo theo¬(p → q) ⇔ p ∧ ¬q
Luật phản đảo (Contrapositive)p → q ⇔ ¬q → ¬p
Mệnh đề đảo (Converse)q → p (không tương đương p → q)
Mệnh đề nghịch (Inverse)¬p → ¬q (không tương đương p → q)
Luật xuất nhập (Exportation)(p ∧ q) → r ⇔ p → (q → r)
Phân bố kéo theo qua hộip → (q ∧ r) ⇔ (p → q) ∧ (p → r)
Phân bố tiền đề qua tuyển(p ∨ q) → r ⇔ (p → r) ∧ (q → r)

📐 Các Quy tắc Suy diễn hợp lý

Tên quy tắcSơ đồ suy diễn
Modus Ponens (Khẳng định)p → q, p ∴ q
Modus Tollens (Phủ định)p → q, ¬q ∴ ¬p
Tam đoạn luận giả thiếtp → q, q → r ∴ p → r
Tam đoạn luận rờip ∨ q, ¬p ∴ q
Chứng minh phản chứng(Tiền đề ∧ ¬q) → 0 ∴ q
Chứng minh theo trường hợpp ∨ q, p → r, q → r ∴ r

🔢 Công thức Giải tích Tổ hợp

Khái niệmCông thức
Hoán vị P_nP_n = n!
Chỉnh hợp A_n^kA_n^k = n! / (n - k)!
Tổ hợp C_n^kC_n^k = n! / [k!(n - k)!]
Tổ hợp lặp C̄_n^kC̄_n^k = C(n + k - 1, k)
Nhị thức Newton(x + y)^n = Σ C(n, k) x^(n-k) y^k
Chia kẹo Euler (nghiệm ≥ 0)C(n + r - 1, r)
Chia kẹo Euler (nghiệm ≥ 1)C(r - 1, n - 1)
